# Question Service - Microservices Project

This is the Question Service in a microservices-based Java application. It provides REST APIs to manage and retrieve questions. It registers itself with the Eureka Server for service discovery.

## Technologies Used

- Java 17+
- Spring Boot
- Spring Web
- Spring Data JPA
- Eureka Client
- H2 / MySQL (configurable)
- Maven

## Features

- CRUD operations on questions
- RESTful API structure
